# AI-Powered-Diabetes-Prediction-and-Health-Monitoring-System
Developed a full-stack healthcare web application using Flask, Machine Learning, SQLAlchemy, and MySQL for diabetes risk prediction, health monitoring, medication tracking, appointment scheduling, and analytical reporting.
## Overview
A Flask-based web application that predicts diabetes risk using Machine Learning and provides complete health monitoring features.

## Features
- Diabetes Risk Prediction
- User Authentication
- Health Dashboard
- Lifestyle Tracking
- Vital Signs Monitoring
- Medication Reminders
- Doctor Appointment Booking
- PDF Report Generation
- Data Visualization and Analytics

## Technologies Used
- Python
- Flask
- Scikit-Learn
- Pandas
- NumPy
- SQLAlchemy
- MySQL
- HTML
- CSS
- JavaScript

## Installation

pip install -r requirements.txt

python app.py
